## 2. 权威口径（施工时必须遵守，不要重新推导）

### 2.1 裁决（01 §1.8 第 2 条、05 §5）

单值顺序，先命中先返回，不叠加：

```text
PASS → WINDOW_CLOSING → BUILD_NOW(标准) → BUILD_NOW(补偿) → EARLY_BET → WATCH
```

- `PASS`：D=Low、W=Low，或 M 出现强负面信号。
- `WINDOW_CLOSING`：此前**已发布**过 `BUILD_NOW` / `EARLY_BET`，且 W 在 14 天内下降 ≥1 档，当前 W ≥ Medium。
- `BUILD_NOW` 标准：`D≥Medium ∧ M=High ∧ W≥Medium ∧ Confidence≥Medium`。
- `BUILD_NOW` 补偿：`D=High ∧ W=High ∧ M=Medium`，且 M 至少含一条 `COMMERCIAL_TRACTION`，或定价/结账持续 ≥ 90 天。**仅凭 `independentDomainsCount ≥ 2`（多站静态 `PRICING_DECORATION`）不再满足补偿。**
- `EARLY_BET`：`D=High ∧ W≥Medium`，或快车道 `D≥Medium ∧ W=High`；M 可为 Low / Medium / Insufficient。
- 其余 `WATCH`；D=Insufficient 时带 `PARTIAL_DATA`。

### 2.2 W 轴（05 §3.3）

```text
pressure = min(100, 30·e_specialist_30d + 40·e_authoritative_30d + 3·volatility_30d)
W_score  = (0.60·serp_weakness + 0.25·(100 − pressure)) / 0.85
```

- `verified_product_count`、`top10_specialist_count`、`new_top10_entrants_30d` **不是 W 的输入**。它们只用于拥挤度透明度、生命周期（`EARLY_WINDOW → CONTESTED`）与 `CROWDING_SIGNAL` 告警。
- 拥挤度不得触发 `WINDOW_CLOSING`，不得限制 GO。
- `CROWDED_LOCKED` 已从 Verdict flags 中删除，任何代码路径都不得再产生它。

### 2.3 GO（01 §1.8 第 5 条、ADR-018、13 §4）

一次原子事务：

```text
reserve 1 次 atomic_go_export_monthly
→ 创建 Project 壳（credential_status='UNVERIFIED'，decision_id 唯一）
→ 解锁该裁决的 AI 点火包
```

> 「解锁」= **授权成立**（存在该用户对该 `decision_id` 的 GO Project）。点火包内容是首次导出时懒装配的，不在 GO 事务里生成；这是实现取舍，见 §5 B4，DSH 不得把它当成「已写解锁行」而不汇报。

- 配额：Pro 每月 3 次，未用完结转一期，结转后余额上限 6；Free 无 GO 权限。
- **没有槽位、没有容量上限、没有活跃 GO 上限、没有质押。** 并发 GO 各扣各的配额，不做任何"最后一个名额"检查。
- 同一用户对同一 `decision_id` 重复 GO：`409 ALREADY_GO`，配额不重复扣减。
- 凭证核验是 GO 之后的可选动作：无截止时间、失败不释放资源、不退还配额。状态 `UNVERIFIED` / `PENDING` / `VERIFIED_OWNER` / `REJECTED`。

### 2.4 公开资格（15 §3）

「已失去抢跑价值」任一满足即可公开：

1. 当前裁决 `WINDOW_CLOSING` 或 `PASS`；
2. 生命周期 `CONTESTED` / `MATURE` / `DEAD`；
3. 连续 14 天（含端点）不是 `BUILD_NOW` / `EARLY_BET`。

活跃的 `BUILD_NOW` / `EARLY_BET` **永不**公开；重新活跃时同一轮 S8 置回 `DRAFT` / 404。没有 45 天延迟、没有槽位满额旁路、没有买断打码。

### 2.5 告警（12 §2）

首发 6 条：`VERDICT_CHANGE`、`WINDOW_CLOSING`、`CROWDING_SIGNAL`、`KILL_CRITERIA`、`PROJECT_SERP_RANK_JUMP`、`CUSTOM_QUERY_PULSE_CONFIRMED`。

`SLOTS_LAST_ONE` 已删除，由 `CROWDING_SIGNAL` 取代：`crowding_daily.verified_product_count` 首次达到 3，或 `new_top10_entrants_30d` 较上次推送增加。只提示竞争加剧，不限制 GO。
